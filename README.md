# Mohamed Ibrahim | Portfolio

A responsive, single-page portfolio website for Mohamed Ibrahim, a web developer and data analyst from Tirunelveli, India.

## Overview

The portfolio highlights:

- About Me
- Python, data analysis, Excel, Power BI, MongoDB, and web development skills
- Python data visualization
- Sales performance analysis
- Personal portfolio website
- Contact information and resume access

## Built With

- HTML5
- CSS3
- Google Fonts (Poppins)
- Python and data analysis tools showcased in the portfolio

## Getting Started

No build tools or dependencies are required.

1. Clone or download the repository.
2. Open `index.html` in a web browser.

For a local development server, run:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.
